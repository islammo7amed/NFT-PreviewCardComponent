# NFT-PreviewCardComponent

A modern and responsive NFT Preview Card built with HTML and CSS for the Frontend Mentor "NFT Preview Card Component" challenge.

---

## Overview

This project showcases a responsive card design that presents information about an NFT — including its image, price in Ethereum, remaining time, and creator details.

---

## Features

- **Responsive layout** that adapts to various screen sizes  
- **Hover overlay effect** on the NFT image with a centered view icon  
- **Interactive text hover states** for better user experience  
- **Soft color palette** and **consistent spacing** for a balanced visual design  
- **Clean and semantic HTML structure** following accessibility best practices

---

## Built With

- **HTML5** for semantic structure  
- **CSS3** (Flexbox) for layout and styling  
- **Google Fonts** (Outfit) for modern typography
